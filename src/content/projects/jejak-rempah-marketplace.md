## Overview

Jejak Rempah Marketplace is a sophisticated application designed to streamline tourism management. It serves multiple stakeholders including sellers, merchants, and super admins, providing a unified platform for operations.

Key features include:
- **Role-Based Management**: Distinct portals for sellers, merchants, and administrators.
- **E-commerce Suite**: Complete set of e-commerce features to facilitate bookings and sales.
- **Payment Gateway**: Integrated secure payment processing for seamless transactions.
- **Authentication**: Robust security with Google OAuth and SMTP for verified communications.

## Technologies Used

- **Next.js**: React framework for building fast and scalable web applications.
- **TypeScript**: Typed superset of JavaScript for better code quality and maintainability.
- **PostgreSQL**: Advanced open-source relational database.
- **Payment Gateway**: Secure transaction processing.
- **Google OAuth**: Secure user authentication.
- **SMTP**: Email services for notifications and verifications.

## Outcome

This project delivers a scalable and efficient solution for tourism management, simplifying complex interactions between various stakeholders and enhancing the overall user experience.
