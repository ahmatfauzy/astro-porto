## Overview

Jagamata is a comprehensive platform dedicated to sustainable eye health. It leverages advanced technology to provide personalized eye care solutions.

Key features include:

- **Smart Acupressure**: Integrated massage recommendations based on fatigue detection results.
- **Disease Detection**: AI-powered detection of potential eye diseases to ensure early intervention.
- **Recommendations**: Personalized suggestions for clinics and medications tailored to user needs.
- **Secure Authentication**: Seamless login experience using Google OAuth and SMTP integration for notifications.

## Technologies Used

- **Flask**: Lightweight backend framework for efficient API handling.
- **Hugging Face**: Integrated for advanced AI models and natural language processing tasks.
- **Flutter**: Cross-platform mobile application development.
- **MySQL**: Relational database management system for structured data storage.
- **Docker**: Containerization ensuring consistent deployment environments.
- **Google OAuth**: For secure and easy user authentication.
- **SMTP**: For reliable email notifications and communication.

## Outcome

Jagamata bridges the gap between technology and personal eye care, offering users an accessible way to monitor and improve their eye health sustainably.
