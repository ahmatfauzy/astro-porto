## Overview

This project involved developing a centralized marketplace platform designed to aggregate product data from various online stores into a single, unified dashboard. The primary goal was to create a more efficient shopping experience for users, allowing them to easily compare products and prices from multiple sources.

## Key Features

- **Product Data Aggregation**: Implemented API integrations with several online stores to automatically collect product data, including details, prices, and availability.
- **Integrated Payment System**: Integrated Midtrans as the primary payment gateway to process transactions securely and efficiently.
- **Search and Filter Functionality**: Developed a robust product search feature and dynamic filters to help users find their desired products with precision.
- **User Dashboard**: Created an intuitive user dashboard where customers can view their purchase history, manage transactions, and track order status.

## Technologies Used

- **Next.js 15 & TypeScript**: For fast, server-rendered React applications.
- **React Query**: Efficient data fetching & caching.
- **Zustand**: Lightweight global state (cart & UI).
- **Tailwind CSS + shadcn/ui**: Component-driven, modern styling.
- **Axios**: HTTP client dengan token interceptor.
- **Laravel**: backend

## Outcome

Harber Marketplace is a fully functional platform that effectively addresses market fragmentation by centralizing product data. The successful integration of Midtrans has not only streamlined the checkout process but also built trust with users through secure transactions. This project has established a strong foundation for future scaling, with a clear path to onboarding new stores and expanding our product catalog while maintaining a seamless user experience.
